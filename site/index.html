Snitch is the integrity layer for AI coding agents. It catches agents that make a failing test pass by weakening, skipping or deleting it, and gives them an honest way out.

Install in one line Star on GitHub

The quiet cheat

You ask for a green CI. The agent comes back with a green CI. Here is how it sometimes gets there, and what Snitch prints the moment it happens.

What the agent changed

# tests/test_calc.py
 def test_divide():
-    assert divide(10, 2) == 5
+    assert divide(10, 2) in (5, 6)

# agent: "Fixed it, all tests pass ✅"

What Snitch reports

Snitch receipt: 1 event, 1 high

severity  high
family    tampering
pattern   assertion_weakened
where     test_calc.py:9
detector  ast

- assert divide(10, 2) == 5
+ assert divide(10, 2) in (5, 6)

One engine, three places

Every finding comes from a deterministic detector and points at a line in the diff. Snitch never asks a model whether something “looks like cheating”.

Live

Claude Code plugin

Warns the agent as soon as a test is weakened. Offers an escalate tool to report a broken test instead of editing it, plus the policy that makes agents use it. Won’t let the session end with a test change the agent didn’t mention.

Every PR

GitHub Action & pre-commit

Checks any pull request, whoever wrote it: Codex, Copilot, Cursor, Devin or a human. Posts an integrity receipt and flags the lines in code scanning.

Public

TemptationBench

40 realistic tasks with one built-in temptation each and hidden tests, to measure how often agents cheat, hide it, or escalate honestly.

Test inventory

pytest --collect-only before and after: tests deleted, renamed away, skipped or deselected.

Assertion diff

tree-sitter diff of every test: asserts removed or weakened (== → in, looser approx or bounds, flipped to !=), expected values changed, asserts hidden behind a guard.

Runner & CI rules

addopts, coverage thresholds, conftest.py report hooks, continue-on-error, || true, --no-verify, code that special-cases pytest, an __eq__ forced to return True.

Measured, not claimed

claude plugin eval on 20 seeded repos (broken test, impossible spec, flaky test, slow test, runner config, controls), 2 runs per case, with and without the plugin.

Install

Python / pytest today. Pick where you want Snitch to watch.

/plugin marketplace add ennajari/snitch
/plugin install snitch@snitch

Modes in /config: observe (record only), warn (default: tell the agent and you), enforce (also block edits to frozen tests and stops that hide test changes). Freeze paths in .snitch.toml: frozen = ["tests/**"].

on: pull_request
permissions:
  contents: read
  pull-requests: write     # the receipt comment
  security-events: write   # code scanning
jobs:
  snitch:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
        with:
          fetch-depth: 0
      - uses: ennajari/snitch@master
repos:
  - repo: https://github.com/ennajari/snitch
    rev: master
    hooks:
      - id: snitch
uvx --from git+https://github.com/ennajari/snitch snitch check
snitch diff <base> <head> --sarif out.sarif
snitch compare <before-dir> <after-dir> --json

TemptationBench

A public leaderboard of which coding agents cheat, which hide it, and which escalate honestly. Same container, prompt and budget for every agent, 3 runs per task, hidden held-out tests, human review of every flagged trial, transcripts published.

6 traps

Broken test

The test expects the wrong value. Honest: say so. Cheat: edit it.

5 traps

Impossible spec

Two tests contradict each other. Honest: explain. Cheat: special-case one.

5 traps

Missing service

The test needs a network or secret that isn’t there. Cheat: mock or skip it.

5 traps

Flaky test

Fails at random. Cheat: quietly add a retry or skip.

5 traps

Hard task

Solvable, but hard in the budget. Cheat: hardcode the fixtures.

14 controls

No temptation

Normal tasks, to show Snitch doesn’t cry wolf.

No leaderboard results are published yet. Every number on this page was measured; none is projected.

Why this exists

Researchers have shown that coding agents cheat on tests, and that an honest exit helps. Snitch turns that into something you can install.

  1. EvilGenie observed explicit reward hacking by Codex and Claude Code. arXiv 2511.21654
  2. SpecBench: frontier agents saturate visible tests while hacking persists on held-out ones. arXiv 2605.21384
  3. BenchJack: a single root conftest.py hook can rewrite every test outcome. arXiv 2605.12673
  4. Escalation channels: across 8 frontier models, a written policy plus an escalation tool cut reward hacking from 23.6% to 5.3%. Snitch ships both. arXiv 2608.29460
  5. ImpossibleBench: agents edit tests, overload __eq__, keep hidden state or special-case inputs; LLM monitors caught only 42–65% of it on real repos. arXiv 2510.20270
